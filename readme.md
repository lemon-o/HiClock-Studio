# HiClock Studio 使用指南

> 本文面向**普通使用者**，介绍 HiClock Studio 是什么、怎么装、怎么用。
> 设备固件（HiClock 智能时钟）的技术细节见仓库根 `README.md`；
> Studio 的架构、设备协议与串流链路等开发者文档见同目录 `README.md`。

---

## 一、HiClock Studio 是什么？

HiClock Studio 是 **Windows 桌面端**的配套软件（.NET 8 + WPF），用来管理你的 HiClock 智能时钟 / 数码相框设备。装上它，你可以：

- **可视化设计表盘样式**：在和真实屏幕一样大小的画布上拖拽文字、图形，调颜色、字体、布局，所见即所得。
- **管理多台设备**：在同一台电脑上查看、连接、批量上传样式到局域网里的多台 HiClock 设备。
- **把电脑画面/数据投到时钟**：USB 直连可投显示器画面、某个窗口、图片/视频；电脑的 CPU/GPU/内存/帧率等实时数据则插不插 USB 都行（走局域网由设备自己画），见下文「屏幕串流」。

简言之：**固件让设备能跑，Studio 让你把设备「打扮」成自己想要的样子，并随时管理它。**

---

## 二、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| 运行库 | **.NET 8 Desktop Runtime（x64）** —— 没装的话安装器会提示你去下载 |
| 屏幕串流 | 显示器 / 窗口 / 媒体模式需要一根 **USB 数据线**；「数据」模式走局域网即可，无需 USB |
| 硬盘 | 约几十 MB（不含可选监控组件） |

> 提示：普通使用**不需要**管理员权限。只有开启「监控环境」（读取更底层硬件数据）时才需以管理员身份运行一次安装脚本。

## 三、如何安装

### 方式一：安装包（推荐普通用户）

1. 到 GitHub Releases 下载 `HiClockStudio_setup_1.0.0.exe`。
2. 双击运行，按向导下一步即可。
3. 若电脑没装 .NET 8 Desktop Runtime，安装器会弹窗提示，点「是」会打开官方下载页；装好运行库后再运行安装包。
4. 安装结束时可勾选「安装监控环境」——它会配置内核态采集服务（Ring0）与 PawnIO 驱动，用于读取更详细的硬件数据。**这一步可选，且需要管理员权限**，不勾也能正常使用大部分功能。

安装完成后，开始菜单 / 桌面会出现 **HiClock Studio** 快捷方式，直接打开即可。

### 方式二：从源码自己编译（开发者）

需要已安装 **.NET 8 SDK**，在 `HiClock Studio` 目录下执行：

```powershell
dotnet restore .\HiClockStudio.sln
dotnet build .\HiClockStudio.sln -c Release
```

或用自带的一键脚本 `编译正式版本.bat` 生成 `publish\win-x64` 发布目录。

> 注意：编译 Studio **不会**编译或烧录固件，两者互不影响。

## 四、五分钟快速上手

1. **打开软件** → 左侧主导航切换到「**设备管理**」。
2. **连接设备**：
   - 输入设备 IP 后点「连接设备」；或点「扫描局域网」自动发现；
   - 设备默认主机名形如 `hiclock-XXXX.local`，换过 IP 也能秒级重连。
3. **打开样式**：把 `.hcb`（上传即用）或 `.hcs.h`（可编译）样文件拖进软件，或点「打开」。
4. **设计 / 微调**：在中间画布上拖动元素、改文字和颜色。
5. **导出设备字体包**：点左侧「字」按钮，选 **`.hcb`** 导出（最适合直接上传到设备）。
6. **上传并启用**：回到「设备管理」，勾选目标设备 → 上传当前样式 → 启用。
7. （可选）**开启串流**：把电脑画面或数据投到时钟，见下文「屏幕串流」。

> 小提示：默认「关闭时最小化到托盘」，所以点关闭按钮程序不会退出，而是缩到右下角托盘继续挂着
> （串流不会断）。要彻底退出请右键托盘图标选「退出」，或在「更多 → 首选项」里关掉该选项。

## 五、功能详解

### 1. 设备管理

- **三种连法**：手动填 IP、一键扫描本机所在网段、或通过 `hiclock-XXXX.local` 主机名自动发现。
- **设备卡片缩略图**：未开启串流时，每张卡片会显示该设备当前屏幕上正在显示的内容，管理多台设备时一目了然。
- **批量操作**：可勾选多台在线设备，批量打开后台网页或上传当前样式。
- 旧版固件仅支持「样式管理」；新版固件还能接收实时遥测数据用于串流。

### 2. 样式编辑器

画布就是一块 240×320（或你设备对应的尺寸）的「虚拟屏幕」，你在上面像做 PPT 一样排版：

- **元素类型**：文本、矩形（四角可独立设圆角）、圆形、直线。
- **编辑能力**：拖动定位、复制 / 删除、图层上下移动与置顶置底、居中；支持 Ctrl/Shift 多选、框选、整组拖动。
- **对齐辅助**：拖动时显示对齐参考线，松手自动吸附，支持边缘对齐与等距分布。
- **撤销 / 重做**：每个样式各自保留 100 步历史，切换样式不丢操作。
- **字体**：
  - 设计阶段可直接用**电脑里已安装的字体**（含中文），并设置像素字号实时预览；
  - 要发给设备用时，点「设备字体包」按钮，软件会把样式里实际用到的字，栅格化成设备能识别的点阵字库，打包进导出文件。
- **导出格式**：
  - **`.hcb`**：运行时单文件包，**上传即用、免编译**，推荐大多数用户；
  - **`.hcs.h`**：可编译单文件格式（样式 + 编译期字库），复制到固件工程里编译烧录，适合要自己编译固件的玩家。

常用快捷键：

| 快捷键 | 作用 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+D | 复制选中元素 |
| Delete | 删除选中元素 |
| 方向键 | 微移选中元素（Shift 放大步长） |

### 3. 屏幕串流（把电脑画面 / 数据投到时钟）

这是 HiClock Studio 最有特色的功能：**把电脑的内容实时显示到时钟的小屏上**。

设备与电脑有两条互不干扰的通道，按内容来源自动选择：

- **USB 数据线**：显示器 / 窗口 / 媒体画面（电脑渲染好再传给设备）。**这几类必须插 USB**。
- **局域网（WiFi）**：只有「数据」模式能走 WiFi —— 电脑只把 CPU/GPU 等**数值**发过去，
  由设备自己画表盘。**不需要 USB 线**，也不重启设备、不打断当前显示模式。

两条通道可以同时用：插着 USB 投屏幕画面的同时，「数据」遥测仍在后台更新。

提供四种内容来源，互斥选择其一：

| 模式 | 显示内容 | 需要 USB？ | 典型用途 |
|---|---|---|---|
| **显示器** | 整块电脑屏幕 | 是 | 把桌面「搬」到时钟上 |
| **窗口** | 指定的某个软件窗口 | 是 | 常驻显示某个程序（如音乐播放器） |
| **媒体** | 本地 / 网络图片、GIF、视频 | 是 | 当个小相框 / 视频框（支持 YouTube 等直链解析） |
| **数据** | 电脑实时硬件数据 | 否（WiFi 亦可） | 做一个「硬件监控表盘」，显示 CPU/GPU/内存/帧率等 |

- **数据模式**可绑定的指标包括：`cpu.usage`（占用率）、`cpu.temp`（温度）、`gpu.usage`、`gpu.temp`、`gpu.vram.used`（显存）、`ram.usage`、`network.download/upload`（网速）、`app.fps`（游戏帧率）等，具体能显示哪些取决于你的硬件与驱动支持。
- **媒体模式**支持本地文件、http(s) 直链，以及主流视频平台链接解析；视频可循环播放，音量只在本机扬声器出声，不影响设备显示。
- **USB 串流为独占模式**：开启后设备专心接收电脑画面，关闭后自动恢复之前的显示模式；中途拔线设备会显示「无信号」并在超时后自动回到正常模式。
- **WiFi 数据串流是非独占的**：设备自己渲染，重启后回到正常模式（串流状态不持久化）；数据长时间不来（约 3 秒）对应指标会自动显示 `--`。

### 4. 可选监控增强组件

想让「数据串流」显示更多、更底层的硬件信息，或想解析 YouTube 视频，可把下列官方组件放到 Studio 的 `tools/` 目录（构建时会自动随包复制）：

| 文件 | 作用 |
|---|---|
| `LibreHardwareMonitorLib.dll` | 读取 CPU/GPU/主板/存储/温度/功耗/风扇等传感器 |
| `PresentMon.exe` | 按前台窗口计算 FPS / 帧时间 |
| `yt-dlp.exe` | 解析 YouTube 等平台的视频直链（未安装时回退到内置解析器） |

> 组件缺失时软件会明确提示并降级，不会崩溃。建议只从官方发布页获取这些文件并核对许可证：
> - <https://github.com/LibreHardwareMonitor/LibreHardwareMonitor>
> - <https://github.com/GameTechDev/PresentMon>
> - <https://github.com/yt-dlp/yt-dlp>

### 5. 首选项（托盘 / 开机自启）

标题栏右上角「**更多**」菜单 →「**首选项**」：

| 选项 | 默认 | 说明 |
|---|---|---|
| 关闭时最小化到托盘 | **开** | 点关闭按钮 / Alt+F4 不退出程序，只收进右下角托盘；从托盘菜单可还原窗口或真正退出 |
| 开机自启 | 关 | 登录 Windows 后自动启动 HiClock Studio，方便长期挂着串流 |

- 关掉「关闭时最小化到托盘」后，关闭按钮与 Alt+F4 都会**直接退出**程序。
- 开机自启由 Studio 写入当前用户的启动项（`HKCU\...\Run`）；若被安全软件拦截，开关会自动回到真实状态。
- Studio 同一时间只允许开一个窗口：重复启动会激活已开的窗口，不会开出第二个（避免两个实例抢设备串口）。

## 六、常见问题（FAQ）

**Q：软件打不开，提示缺少 .NET 8？**
A：到 <https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0> 下载安装「.NET 8 Desktop Runtime（x64）」即可。

**Q：搜不到 / 连不上设备？**
A：请确认：① 电脑和设备在同一局域网；② 设备已配网并正常开机；③ 防火墙未拦截。也可直接填设备 IP 连接；设备主机名 `hiclock-XXXX.local` 通常能自动发现。

**Q：开启串流后屏幕黑屏 / 显示「无信号」？**
A：先确认 **USB 已插好**且串流开关已开；再确认所选串流样式尺寸与设备屏幕一致（尺寸不符设备会拒收帧）；媒体 / YouTube 解析失败时设置里会有提示。若用的是「数据」模式，检查设备是否在同一局域网（WiFi 数据串流不需要 USB）。

**Q：点了关闭按钮，软件好像没退出？**
A：默认开启了「关闭时最小化到托盘」，程序会藏到右下角托盘继续运行。彻底退出请右键托盘图标选「退出」，或在「更多 → 首选项」里关闭「关闭时最小化到托盘」。

**Q：样式上传到设备后字体不对 / 显示空白？**
A：设计用的 Windows 字体需要点「设备字体包」导出，软件才会把它转成设备点阵字库打进 `.hcb`。直接用没导出的样式上传，设备可能缺少对应字库。

**Q：数据串流里某些指标不显示？**
A：取决于硬件、厂商驱动以及是否安装了 LibreHardwareMonitorLib / PawnIO。缺失的传感器自然数不出来，属正常现象。

**Q：能同时管理多台设备吗？**
A：可以。设备管理页支持手动 + 扫描发现多台设备，并能批量上传样式、批量打开后台。
